AI-провайдер

💡 Что это: через какого провайдера работать.
📖 Какой выбрать
  • ProxyAPI — РФ, оплата картой, дороже OpenAI на 20%
  • OpenAI — напрямую, нужна зарубежная карта
  • Claude — Anthropic, качество выше
  • Gemini — Google, есть бесплатный тариф
  • DeepSeek — Китай, самый дешёвый
💡 Что это: ключ клиента. Если пусто — используется ваш общий ключ платформы.
📖 Как получить
  • ProxyAPI: личный кабинет → Ключи API
  • OpenAI: platform.openai.com → API Keys
  • Claude: console.anthropic.com → API Keys
  • Gemini: aistudio.google.com → Get API Key
  • DeepSeek: platform.deepseek.com → API Keys
💡 Оставьте пустым — будет использован URL по умолчанию для выбранного провайдера.
