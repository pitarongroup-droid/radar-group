💡 Что это: веб-приложение Google для добавления строк в таблицу.
📖 Как настроить (5 минут)
  1. Откройте свою Google-таблицу
  2. Расширения → Apps Script
  3. Удалите весь код → вставьте: 
    function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSheet();
  const data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    new Date(),
    data.name || '',
    data.phone || '',
    data.message || ''
  ]);
  return ContentService.createTextOutput('OK');
}

  7. Развернуть → скопировать URL
